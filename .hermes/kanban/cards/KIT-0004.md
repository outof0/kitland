## Outcome

Agents can add disjoint vertical slices without hand-editing competing central
registries. Generated indexes and conformance checks prove catalog, core, web,
browser extension, VS Code, documentation, and release-manifest coverage.

## Acceptance criteria

- [ ] Scaffold accepts a committed inventory id; arbitrary unplanned tools fail.
- [ ] Generated files are deterministic and checked for drift.
- [ ] Every `available` platform contract requires a renderer/command adapter.
- [ ] Shared test vectors run against every required host adapter.
- [ ] Per-tool bundle/package/security budgets are reportable by slug.
- [ ] Parallel-agent ownership and integration workflow are documented.
