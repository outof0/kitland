## Outcome

Visitors can open a production-quality Kitland landing page that matches
`design.pen` (desktop / tablet / mobile), uses official Kitland assets, and
converts to the workbench CTA.

## Context

First product surface for the monorepo. Establishes Vite + React + Tailwind +
Kitland token pipeline before tool workspace and extensions.

## Acceptance criteria

- [x] Sections: Navbar, Hero, Tool rail, Stats, Catalog, Principles, CTA, Footer
- [x] Official Kitland lockup/favicon assets used
- [x] Responsive layout for mobile (~390), tablet (~768), desktop (1440)
- [x] Semantic landmarks, skip link, keyboard-focusable CTAs
- [x] `pnpm typecheck` and `pnpm build` pass for `@kitland/web`
- [ ] Independent visual review against design.pen frames
- [ ] AstryX primitives adopted for interactive controls (follow-up)

## Non-goals

- Full tool workbench functionality
- Nitro server routes
- VS Code / Chrome extensions
- Analytics, cookies, forms

## Architecture notes

- `apps/web` is the landing host
- Kitland tokens in CSS variables; Tailwind v4 `@theme` mapping
- AstryX deferred to a foundation card (landing is mostly static marketing layout)

## Test plan

- Unit: n/a for static marketing v1
- Manual: breakpoints, keyboard, reduced motion, logo fidelity
- Build: `pnpm --filter @kitland/web build`

## Security, privacy, and accessibility

- No third-party trackers
- Skip link + focus-visible styles
- Decorative icons marked aria-hidden
