## Outcome

A single **ship-quality** Base64 tool screen on Web that:

1. Matches `design/design.pen` frames for tool workspace (visual + interaction density).
2. Uses one **clear interaction model** (no lying CTAs, no control soup).
3. Is the **only approved template** for implementing the next tools.

After this card, a developer (or agent) can open Base64 next to the design and agree they are the same product experience at the declared breakpoints.

## Context

### Why this is P0

Landing is craft-complete; the tool workspace was scaffolded as an engineering spike. PM review found the slice technically useful but product-incorrect. This card rebuilds the golden path.

### Surfaces

- **In scope:** `apps/web` tool shell + Base64 page; theme / favorites / sidebar prefs.
- **Out of scope:** VS Code, Chrome, Nitro, full catalog, remaining tools.

## Acceptance criteria

### A. Design fidelity

- [x] **A1.** Desktop shell: sidebar + top bar + tool header + mode + split + rail + status (structure from Z1RWQB metrics in CSS).
- [x] **A2.** Sidebar brand / sections / offline footer; favorites from storage (D6).
- [x] **A3.** Tokens from `tokens.css` / design variables; primary button white label.
- [x] **A4.** Responsive CSS: editor stacks &lt;1280px; sidebar becomes an accessible overlay drawer. Intentional collapses documented below.
- [x] **A5.** Dark default + light toggle; both themes via `data-theme`; persist D7.

### B. Interaction model

- [x] **B1.** Live `runBase64` on input change.
- [x] **B2.** Mode segment and center Swap safely move a valid, fitting result into input before changing direction.
- [x] **B3.** Output toolbar Copy + Save are contextual result actions with an accessible name and short control-local confirmation.
- [x] **B4.** Sample, contextual Clear, and disclosed Share input work.
- [x] **B5.** Rail is Swap-only; it does not duplicate Copy or Save.
- [x] **B6.** Input toolbar: copy, upload, clear; output upload disabled.
- [x] **B7.** Invalid decode → `role="alert"` + actionable text; empty input → Ready, no error.
- [x] **B8.** Status bar stable chip/stats/B64 only.
- [x] **B9.** No Wrap chrome; text wraps by default.

- [x] **C3.** Sidebar collapse persist.

- [x] **C5.** Landing generic CTAs → `/explore` (desktop, tablet, mobile); Base64 is discoverable from the catalog.
