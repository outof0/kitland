# Support

Use the [repository issue chooser](https://github.com/outof0/kitland/issues/new/choose)
for reproducible bugs and feature requests.
Include the affected tool, browser/OS, exact non-sensitive input or a minimal
fixture, expected behavior, and actual behavior.

For security concerns, use the private process in [SECURITY.md](SECURITY.md).
Do not post credentials, tokens, keys, private documents, or production URLs
containing sensitive data in public support threads.

The project is maintained on a best-effort basis. Clear reproductions and
focused pull requests are the fastest way to help resolve an issue.
