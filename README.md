## Layout

```text

brand/          Logos, icons, tokens, voice
design/         design.pen + HTML export reference
```

## Develop

Node **≥ 22**, pnpm **9** (Corepack recommended).

```bash
pnpm install
pnpm dev
```

```bash
pnpm typecheck
pnpm build
```
