# Architecture decision records

Create one ADR for a consequential, durable choice such as a public API
contract, tool-route delivery model, persistence policy, remote service,
security boundary, or package publication strategy.

Each ADR should include context, options, decision, consequences, migration or
rollback plan, owner, and date. Superseded ADRs remain in this directory with a
link to their replacement.
